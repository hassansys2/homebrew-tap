# hassansys2 Homebrew tap

```sh
brew tap hassansys2/tap
brew trust hassansys2/tap
brew install --cask remote-desktop-toggle
```

| Cask | Description |
|---|---|
| [remote-desktop-toggle](https://github.com/hassansys2/remote-desktop-toggle) | Menu-bar switch to turn Chrome Remote Desktop access on and off |

Casks here are updated automatically by each project's release workflow.
